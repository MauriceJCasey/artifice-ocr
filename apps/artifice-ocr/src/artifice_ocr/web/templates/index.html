    Segmentation options

    Detecting page layout

    Whole page (passthrough) treats the entire page as one region. No setup, no download: this is what runs by default. Not installed on this machine.

    Automatic layout detection (doclayout-yolo) is a pretrained model that finds the regions on a page by itself, such as text blocks, titles, and figures. Good for typeset pages with mixed layout, like multiple columns or embedded images. Downloads a model the first time it runs. Not installed on this machine.

    Line-level detail (kraken) additionally detects individual line baselines and reading order, not just regions. It’s the tool of choice for handwritten or otherwise complex historical material where precise line boundaries matter. Works best on black-and-white (bitonal) scans; it still runs on color or grayscale images, just less reliably. Needs an extra install. Not installed on this machine.

    Finding hand-added annotations

    Diff-residual (diff-residual) is a different kind of tool: it is not a layout detector. Give it a clean reference scan of the same page with no annotations, and it finds what was added by hand, such as underlines and marginalia, by comparing the two. Pick it only when you have that second reference image; if it can’t align the two reliably, it reports an error rather than guessing. Not installed on this machine.
